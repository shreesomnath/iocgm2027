\section{Introduction}
This research plan outlines a comprehensive workflow to model landslide susceptibility in the Arun River Basin, Nepal, using 2020--2026 data. The core innovation lies in the \textbf{Hybrid Rainfall Fusion} (DHM + GPM) and the \textbf{Sentinel-1/2 Synergy}.

\section{Research Gaps \& Literature Review}
\begin{itemize}
    \item \textbf{Temporal Gap:} Existing maps (Durham/BGS) end in 2020. This study covers the 2021--2026 era.
    \item \textbf{Data Gap:} Most models use only optical data. We utilize Sentinel-1 SAR as a moisture proxy.
    \item \textbf{Explainability:} Shifting from "black-box" ML to SHAP-based Explainable AI (XAI).
\end{itemize}

\section{Methodology}
\subsection{Hybrid Rainfall Fusion}
We address DHM Nepal data gaps (due to COVID-19/Earthquake legacy) by performing a linear bias correction on GPM IMERG satellite data using available DHM station records.
\begin{equation}
    P_{fused} = 
    \begin{cases} 
    P_{DHM} & \text{if data exists} \\
    \alpha \cdot P_{GPM} & \text{to fill gaps}
    \end{cases}
\end{equation}

\subsection{Modeling}
We employ an \textbf{XGBoost} ensemble with an ablation study:
\begin{itemize}
    \item Model A: Static Topography
    \item Model B: Topography + S2 (NDVI)
    \item Model C: Topography + S2 + S1 (Full Synergy)
\end{itemize}
